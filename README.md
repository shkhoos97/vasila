# 💬 Telegram Бот «Пикап-Мастер & НЛП Эксперт»

Интеллектуальный Telegram-бот, выступающий в роли опытного наставника по мужской харизме, психологии соблазнения и прикладному НЛП. 

Бот умеет анализировать **текст переписок** и **скриншоты диалогов** (из Telegram, Tinder, WhatsApp, Pure, VK, Instagram и др.), считывать скрытый подтекст, определять баланс значимости и генерировать эффективные варианты ответов.

---

## 🚀 Основные возможности

1. **Мультимодальный анализ скриншотов**:
   - Пользователь отправляет скриншот переписки. Бот с помощью зрения нейросети (GPT-4o) распознает реплики, тон и динамику диалога.
2. **Анализ текстовых диалогов**:
   - Поддержка вставки скопированного текста или пересланных сообщений.
3. **Глубокая психологическая диагностика**:
   - Оценка уровня интереса девушки (высокий, средний, холод, шит-тест).
   - Определение баланса значимости и фрейма (кто ведущий, а кто ведомый).
   - Предупреждение о критических ошибках (оправдания, навязчивость, избыточная длина сообщений).
4. **3 тактических варианта ответа под ключ**:
   - 🌶 **Игривый / Бантер / Флирт**: дерзкий юмор, сбивающий шаблон и создающий романтическое напряжение.
   - 🎩 **Уверенный / Калиброванный**: взрослая мужская позиция, ведущая к сближению.
   - 🔮 **Интригующий / НЛП**: холодное чтение, открытые петли (Open Loops), стимулирующие интерес.
5. **Интерактивные сценарии (кнопки)**:
   - Запрос дополнительных 3 вариантов.
   - Стратегия плавного перевода переписки в свидание.
   - Составление психологического портрета девушки и её метапрограмм.

## 🛠 Технологический стек

- **Python 3.10+**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram ботов.
- **OpenAI API / GPT-4o** — обработка текста и изображений (поддерживает любые совместимые API: OpenRouter, DeepSeek, локальные модели).
- **Pydantic Settings & Python-dotenv** — валидация конфигурации и переменных окружения.

## ⚙️ Установка и запуск

### 1. Клонирование или распаковка проекта
Перейдите в директорию с проектом:
```bash
cd pickup_master_bot
```

### 2. Создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # На Linux/macOS
# или venv\Scripts\activate на Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваши ключи:
- `TELEGRAM_BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`).
- `OPENAI_API_KEY` — ключ доступа к API OpenAI (или совместимому провайдеру).
- `OPENAI_BASE_URL` — (опционально) укажите прокси-адрес или URL совместимого сервиса (например, OpenRouter: `https://openrouter.ai/api/v1`).
- `OPENAI_MODEL` — по умолчанию `gpt-4o` (рекомендуется для анализа скриншотов).

### 5. Запуск бота
```bash
python main.py
```

## 🐳 Запуск через Docker

В проекте можно использовать Docker для надежной работы на сервере:

**Dockerfile:**
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python", "main.py"]
```

Сборка и запуск:
```bash
docker build -t pickup-master-bot .
docker run -d --name pickup-bot --env-file .env --restart unless-stopped pickup-master-bot
```
